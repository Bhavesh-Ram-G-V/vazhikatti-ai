🏛️ Vazhikatti AI (வழிகாட்டி AI)

Simple Tamil Welfare Navigator powered by Gemma 4 31B-IT

Vazhikatti AI helps citizens of Tamil Nadu discover government welfare schemes they qualify for using simple spoken Tamil or one-tap profile selections. Built specifically for elderly, low-literacy, and rural citizens, it removes complex forms and bureaucratic jargon while ensuring 100% user privacy (Zero PII collection).

🌟 Key Features

🗣️ Tamil Voice Input & Audio Response: Speak naturally in Tamil (ta-IN) and listen to scheme details read aloud.

🤖 Gemma 4 31B-IT Intelligence: Evaluates unique citizen inputs dynamically against state eligibility rules.

🔒 Zero-PII Privacy: No Aadhaar numbers, phone numbers, or bank account details collected.

🎨 High-Contrast "Warm Horizon" UI: Large fonts, simple buttons, and high contrast designed for low-vision and non-literate users.

⚡ One-Tap Test Scenarios: Instant demo cards for quick evaluation during presentations.

🏛️ Supported Welfare Schemes

Kalaignar Magalir Urimai Thittam (மகளிர் உரிமைத் தொகை)

Indira Gandhi National Widow Pension (விதவை ஓய்வூதியத் திட்டம்)

Pudhumai Penn Scheme (புதுமைப் பெண் திட்டம்)

Chief Minister's Comprehensive Health Insurance (மருத்துவக் காப்பீட்டுத் திட்டம்)

Uzhavar Padhukappu Thittam (உழவர் பாதுகாப்பு திட்டம் - Farmers' Welfare)

Differently Abled Pension (மாற்றுத்திறனாளிகள் உதவித் தொகை)

🛠️ Tech Stack

Frontend: React, Tailwind CSS, Web Speech API (Voice Input & Text-to-Speech)

Backend Intelligence: Google DeepMind Gemma 4 31B-IT (gemma-4-31b-it)

Prototyping Environment: Google AI Studio

🚀 Quick Start for Judges

Running the Single-File Demo:

Save the code as index.html.

Double-click to open it in Google Chrome or Microsoft Edge.

Select Gender (ஆண் / பெண்) and tap the microphone or click a Quick Demo Scenario.
